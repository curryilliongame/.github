# Curryillion 🏀

**Play NBA trivia. One more shot.**

Curryillion is a basketball trivia play hub. Take on 10 timed NBA prompts and choose how you score: **Crowd** rewards popular valid answers, while **Rare** rewards less common correct picks. Every choice becomes a shot.
